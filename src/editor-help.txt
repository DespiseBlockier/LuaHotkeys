LuaHotkeys reference

Write a Lua 5.1 script and click Run to start it. Use Stop to release its hotkeys. New scripts use .lhk, and .luahotkeys and .lua files can also be opened.

Autocomplete
Type part of a function or keyword to see suggestions, or press Ctrl+Space. Use the arrow keys to select and Tab or Enter to insert. Escape closes the list. Function completions put the caret between the parentheses.

Example

hotkey("Ctrl+Alt+J", function()
    type_text("Hello from LuaHotkeys!")
    press("Enter")
end)

LuaHotkeys functions

hotkey(combo, callback)
Registers a global shortcut when the script starts. The callback runs each time you press the combination.

type_text(text)
Types text into the focused window. A newline sends Enter.

press(combo)
Sends a key or a combination such as "Ctrl+S", "Escape", or "Enter".

click([button])
Clicks at the current pointer position. The default is "left". You can also use "right" or "middle".

move_mouse(x, y)
Moves the pointer to screen coordinates in pixels.

mouse_pos()
Returns the current pointer's x and y coordinates.

sleep(milliseconds)
Pauses the script for the specified number of milliseconds.

run(program, ...)
Opens an app, file, or URL. Pass command-line arguments as separate strings.

log(...) and print(...)
Write values to the Activity panel.

Shortcut names
Combine Ctrl, Alt, Shift, or Win with a letter, digit, function key, or a key name such as Left, PageDown, Tab, Space, or NumPad1. Names are case-insensitive. Choose another combination if Windows reports a conflict.

Explorer and updates
Installed copies register .lhk and .luahotkeys during setup. For a portable copy, use Associate files in the tray menu to add Explorer's New and Edit actions. Click Update in the editor to check GitHub and update the current copy in place.
