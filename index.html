Install LuaHotkeys on Linux

The x86-64 terminal runner supports Arch Linux and openSUSE Tumbleweed. Global hotkeys and input automation require an X11 session.

Download the Linux installer, then run it from your download folder. It registers the signed repository and installs LuaHotkeys using your package manager.

sh ./install-linux.sh

To add the repository first, run the installer with --repo-only. Then install by name.

Arch Linux

sudo pacman -S luahotkeys

openSUSE Tumbleweed

sudo zypper install luahotkeys

Run a script

luahotkeys --run ./my-script.lhk
